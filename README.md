# AtelierCoutureManager

Application de gestion dédiée aux ateliers de couture.

## Présentation

**AtelierCoutureManager** a pour objectif de centraliser et de simplifier la gestion quotidienne d’un atelier de couture. Le projet pourra notamment aider à suivre les clients, les commandes, les retouches, les créations et l’avancement des travaux dans un espace unique.

Le dépôt est actuellement initialisé et constitue la base du développement de l’application.

## Objectifs du projet

Le projet vise à proposer une solution claire et évolutive pour :

- gérer les informations des clients ;
- enregistrer et suivre les commandes ;
- organiser les mesures, retouches et demandes particulières ;
- suivre l’état d’avancement des travaux ;
- faciliter la gestion des échéances et des livraisons ;
- améliorer la visibilité sur l’activité de l’atelier.
